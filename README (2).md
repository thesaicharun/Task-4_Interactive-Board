# Sales Financial Dashboard

## Objective

The objective of this project is to design an interactive business dashboard using the Sales Financial Dataset. The dashboard enables business stakeholders to monitor performance, identify trends, and make data-driven decisions through effective data visualization.

## Tools Used

* Power BI Desktop
* Sales Financial Dataset (Kaggle)
* GitHub

## Dashboard Features

* KPI Cards for Total Sales, Total Profit, and Growth
* Interactive Slicers and Filters
* Time-Series Analysis of Sales and Profit
* Regional and Product-wise Performance Analysis
* Consistent Color Theme
* User-Friendly Dashboard Layout
* Navigation Between Dashboard Sections

## Key Visualizations

* Sales Trend Line Chart
* Profit Analysis Bar Chart
* Revenue Distribution Chart
* Region-wise Sales Performance
* Monthly Growth Analysis
* KPI Summary Cards

## Steps Performed

1. Imported and cleaned the Sales Financial Dataset.
2. Created data relationships and measures.
3. Designed KPI cards for business metrics.
4. Built interactive charts and visualizations.
5. Added slicers for dynamic filtering.
6. Implemented time-based trend analysis.
7. Applied a consistent dashboard theme.
8. Tested dashboard interactivity and usability.

## Business Value

This dashboard helps stakeholders:

* Track overall business performance.
* Monitor sales and profit trends.
* Identify high-performing products and regions.
* Analyze growth over time.
* Make informed strategic decisions.
